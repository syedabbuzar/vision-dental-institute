# Vision & Dental Institute

FINAL DESIGN UPDATE – MEDICAL INTERFACE THEME

Use the THIRD selected visual reference: Futuristic Medical Interface.

The website must have a premium futuristic medical technology aesthetic.

Final color palette:

Deep Navy: #071C2A

Neon Teal: #16D6C5

Pure White: #FFFFFF

DESIGN REQUIREMENTS:

Make the hero section cinematic with a deep navy background.

Display an ultra-realistic human eye with animated cyan ophthalmic scanning rings, tracking indicators and scanning beams.

Build the dental section around a realistic 3D teeth model with a medical scanning interface.

Use subtle HUD elements, thin cyan outlines, animated grids and technical markers.

Use dark navy backgrounds selectively for immersive medical sections.

Use white and ice-blue backgrounds for hospital information, services, doctors, gallery and contact sections.

Use neon teal for CTAs, active states, scanner indicators and selected highlights.

Keep the design premium, sophisticated and medically trustworthy.

Use smooth Motion animations and cinematic transitions between eye and dental experiences.

Avoid making the website look like a gaming interface. Medical HUD elements must remain subtle and elegant.

The final experience must look like an advanced international ophthalmology and dental healthcare brand, not a generic hospital template.

Maintain readability, accessibility, mobile responsiveness and performance.
IMAGE AND 3D ASSET REQUIREMENTS:

Do not use emoji or cartoon illustrations.

Use ultra-realistic medical photography and

high-quality 3D medical assets.

Eye section:

Use realistic human iris and eyeball textures.

Dental section:

Use realistic human teeth, gums and enamel textures.

Medical interface:

Create animated scanning effects using Motion

and Three.js.

Use original hospital images wherever available.

Optimize all images for web performance.

Do not use broken or placeholder image URLs.
